Custom firmware for the Hidizs AP30. Everything runs in this page; nothing is uploaded.

  1. Download the official AP30 firmware V1.7.8 from the Hidizs download center and unzip it to get HIFIYF18.IMG.
  2. Choose that file below. The page checks it and builds amuletOS from it.
  3. Save the result, copy it to the AP30's internal storage as HIFIYF18.IMG, eject and restart the player.

Going back: the AP30 only installs a file stamped newer than what it runs, so the official file can't be copied over amuletOS as it is. "Go back" gives your official file a newer stamp and the matching checksum and changes nothing else. After that, install a later amuletOS release (this one is older than the re-stamped file).

The patch carries only amuletOS's own code, art and font; everything from Hidizs comes from your own copy of the official file. The page refuses any other input, and only offers a file whose SHA-256 matches amuletOS __VERSION__:
